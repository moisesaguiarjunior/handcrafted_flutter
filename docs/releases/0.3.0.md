# 0.3.0 release

This release gathers the material foundation and its original interactive
examples into one immutable Git source version. It is still experimental and
pre-1.0. The first hosted upload completed on 2026-11-18.
[Install from pub.dev](https://pub.dev/packages/handcrafted_flutter); its archive
matches the immutable v0.3.0 source tag.

## What you can build

- Paper/cloth-themed native controls, choices and pressed headings.
- Seeded EVA, cotton, velvety nap and leather, plus short matte nap overlays.
- Colored interlaced cords, irregular recessed seams and layered paper bands.
- Shared directional light over prepared volume and curved ribbons; independent
  edge width, thickness, ground lift and shadow softness.
- Imported cuts that keep full transparent paint margins and shared native input
  transforms when fitted to their declared visible bounds.
- Conservative decorative stroke envelopes, alongside bounded freehand capture.

The light studio demonstrates the same primitives under an example-only spatial
lamp: direction and distance falloff are sampled at each piece center. Rotate a
piece or change its silhouette without moving the light. It is not a per-pixel
3D point-light solver. Clay-like volume remains an example recipe.

## Upgrading from 0.2.0

Update exhaustive CraftMaterial switches for new material cases. Keep immutable
source pins and lockfiles. Existing defaults are preserved unless the changelog
explicitly describes a fix. `CraftPlacement.fit` rejects numerically unreliable
paint windows/poses; keep source and visible bounds in coherent local units.
`craftStrokeBounds` reports local decorative bounds; account for output scaling
and device pixels in the host's raster gutter.

See [full changelog](../../CHANGELOG.md), [compatibility](../compatibility.md),
[light studio](../light-studio.md), and [publication process](../publishing.md).

## Evidence and remaining limits

Format, strict analysis, package/example tests, native raster comparisons and
focused Chrome widget tests protect the source. A generated Android debug host
runs a smoke of lamp dragging, shape selection and paint/thread gallery layouts.
Emulation does not establish phone performance. No iPhone benchmark, physical
screen-reader certification or general multi-platform shipping matrix is claimed.
Browser-visit status and exact independent review are recorded separately.
