# Runnable use cases and README media

The repository presentation follows the useful pattern in the maintainer's [Fluvie
fork](https://github.com/moisesaguiarjunior/fluvie): rendered output beside small API snippets, linked to full runnable examples.
No Fluvie video/physics API or upstream artwork is implied by this package.

## Live examples

From example/, run `flutter run -d chrome -t lib/main_showcase.dart`.
`main_showcase.dart` offers the keepsake card, hanging pieces and kite tail,
real native actions, finite replay and still pose. `main.dart` remains the detailed
material-control gallery. `use_cases.dart` owns the compositions shared by the
live gallery and capture harness; do not introduce a separate mockup renderer.
The fixed artwork stage scrolls horizontally in narrow windows; it does not
shrink native text/actions to squeeze them into the illustration. Enlarged text
switches the keepsake card to a flowing composition instead of its fixed artwork
stage.

The keepsake paper uses content sizing with a minimum height at ordinary text
sizes, and the flowing large-type composition includes 150% text scaling.
A scroll view does not automatically pause SceneEntrance: viewport visibility
must be supplied by the host as active. The showcase does not have such a detector;
its motion is finite and stops on completion.

The controls do not save user data or open real collections. Their demo counter
shows actual Flutter action dispatch. Motion is authored and finite, not shared
wind, buoyancy, cloth simulation or a physical mobile. System reduced motion
continues to take precedence in SceneEntrance.

## Reproduce the images

From the package root:

```sh
flutter test tool/capture_showcase.dart
bash tool/encode_showcase.sh
```

The capture command loads the example's bundled Inter/Caveat fonts and sets pixel
ratio 1. Static samples are 440x340 logical pixels; the banner is 1100x500.
Animation samples use 51 explicit progress values from 0 to 1, with a stable seed
and palette. This bypasses wall-clock drift without replacing the live artwork.
FFmpeg encodes those PNGs at 12 fps, a 96-color palette and a repeating GIF loop.
The loops replay the finite entrance; they do not establish ambient animation.
This sampled capture is not a phone frame-rate or input-latency benchmark.

Outputs:

| Source | Tracked README asset |
| --- | --- |
| build/showcase/hero.png | assets/hero.png |
| build/showcase/keepsake.png | assets/keepsake.png |
| build/showcase/hanging/frame_*.png | assets/hanging-parts.gif |
| build/showcase/kite/frame_*.png | Untracked; replacement artwork awaits visual review |

Intermediate frames stay ignored under build/. The original material comparison
is generated by tool/capture_materials.dart. Captures are explicit; ordinary
checks never rewrite documentation images or golden baselines.

Inspect the static banner/card and intermediate poses after changing examples.
The images are synthetic developer demonstrations. Review application artwork
separately from these examples. Do not describe the illustrated punctures as displaced cloth fibers.

## Typography and licensing

Inter and Caveat are unmodified, SIL OFL 1.1 font files copied into example/assets/
with their original copyright/license notices. They are example/capture assets,
not a font dependency exported by the Dart library. See dependencies.md and
provenance.md. FFmpeg is an external developer tool used only to encode these
GIFs; no FFmpeg binary or codec library is distributed by this package.

## README cover and distinct relief objects

`flutter test tool/capture_cover.dart` renders the same MaterialCover and
ReliefObjectsSheet as `example/lib/main_cover.dart`. Outputs are
`build/cover/material-cover.png` (1200×750) and
`build/cover/relief-objects.png` (1100×560), copied explicitly to
`doc/screenshots/relief-objects.png` for the package preview.
These are new documentation compositions, not updates to golden baselines.
The fixed poster uses the controlled font/scale capture baseline; the live cover
scrolls its artboard horizontally, while the separate object studies reflow.
Application layouts must be validated separately at their own text scales.

A raised shell, pressed feather and crescent replace repeated botanical motifs
in the documentation presentation. The cover combines real textured substrates,
contour-matched cord, embroidered sprig, torn paper, layered pigment and a native
button. Cast shadows follow each actual cut; they do not imply displaced fabric.
The poster has no animation clock. Existing motion captures remain separate.
