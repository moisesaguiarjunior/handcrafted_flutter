# 0.4.0 source release

Version 0.4.0 gathers the post-0.3.0 material studies and rendering fixes into an
immutable Git source tag. It remains experimental and pre-1.0. Hosted 0.3.0 and
all earlier tags retain their original bytes and SDK constraints. This source
release does not upload 0.4.0 to pub.dev.

The previously planned 0.3.1 SDK-only patch was not tagged or published. Its
compatibility work is included here, alongside the new public profile case that
requires a minor version.

## What's included

- `CraftVolumeProfile.padded`: a bounded, scale-aware whole-face profile using
  the canonical normals, lighting and shadows. Original sheet/rounded profiles
  and indices are preserved.
- Independent `CraftNap.fiberLength`, `curl` and opt-in `edgeFuzz`, with explicit
  paint bounds and bounded candidates. The same matte finish works over all nine
  materials and padded cuts; existing short-nap defaults retain their pixels.
- Original pillow studies with short plush, curled sherpa, optional projected
  depth, shared light and native filling/seam controls.
- Example-owned continuous paper/pigment, soft masks and repeating-print proofs.
  These are bounded source-domain studies, not arbitrary-size document support.
- A tested Flutter 3.35.7 / Dart 3.9.2 floor, alongside the locked 3.47.9 /
  3.13.7 baseline, and standard Flutter lints with strict project rules.
- Stable image clipping across pose changes; owner-scoped shader reuse and
  explicit disposal; selected choices that reflow at narrow/enlarged layouts;
  corrected dotted brush orientation; published HTTPS sharing on native hosts
  and sanitized browser study links.

## Upgrading from 0.3.0

Update exhaustive `CraftVolumeProfile` switches for the new `padded` case:

```dart
String profileLabel(CraftVolumeProfile profile) => switch (profile) {
  CraftVolumeProfile.sheet => 'Sheet',
  CraftVolumeProfile.rounded => 'Rounded',
  CraftVolumeProfile.padded => 'Padded',
};
```

The new nap parameters are optional; defaults retain the previous short fibers.
When enabling fringe, reserve `nap.paintBounds` independently of native text,
semantics and touch targets. Caller clips still apply; real holes can receive
fringe at their boundary while canceled/hidden contours do not.

Supply a new immutable `Path` when changing `CraftImagePart.sourceClip`.
Pose-only updates now reuse the existing render clip. Selected labels may wrap
under narrow constraints instead of overflowing; allow the native button to grow
in height. Dotted brush dabs deliberately change on nonhorizontal paths to keep
the artistic tilt aligned with the canvas tangent.

Use the source tag while hosted 0.4.0 is unavailable:

```yaml
dependencies:
  handcrafted_flutter:
    git:
      url: https://github.com/moisesaguiarjunior/handcrafted_flutter.git
      ref: v0.4.0
```

Commit the consumer lockfile and compare affected visuals before migrating an
application. No consumer dependency is updated automatically by this release.

## Archive boundary

The prospective Pub payload keeps the library, core tests, runnable example and
its licensed runtime assets. Full docs and root/example capture entrypoints stay
Git-only: those scripts need the excluded root tools and example test helpers.
Use the Git checkout for captures. A synthetic nested-tool probe protects this
boundary; no library behavior or runtime asset is removed. The dry-run reports a
rounded 2 MB compressed payload, not a byte-exact download/install measurement.

## Validation and limits

The source base passed 162 library and 159 example tests, focused native/Chrome
regressions, release web builds and zero-warning publication/Dartdoc dry-runs.
CI checks both SDK endpoints, including Chrome resource/compositing regressions.
Exact independent review and release-candidate CI remain separate source gates.
See [review records](../reviews/local-review-record.md).

Partial-strength grain retains saveLayer: the 162-case direct-alpha experiment
was native-identical but changed 59 Chrome cases (154 channels, maximum delta
28). Owner-local shader caching does not provide shared textures across owners
or prove a frame-time/memory gain on phones.

Focused renderer-override probes cover shader lifetime in ordinary CanvasKit,
Skwasm and forced CanvasKit/Wasm tests. They do not certify a complete Wasm app,
a desktop shipping matrix or Android/iOS physical-device performance. Emulation,
test coverage and illustrative padding/fibers do not establish cloth physics,
optical fur scattering or physical assistive-technology acceptance.
