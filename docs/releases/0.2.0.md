# 0.2.0 — composable materials and living studies

An experimental MIT Git source release, built on the unchanged 0.1.0 baseline.
It is not published on pub.dev. Flutter 3.47.9 / Dart 3.13.7 remains the tested
minimum. [Full changelog](../../CHANGELOG.md).

## New package APIs

- Host-owned `CraftTheme` material roles, `CraftPanel`, `CraftButton` and
  `CraftChoice` compose paper/cloth decoration with native text, focus, actions
  and selected semantics. Decoration budgets never shrink the native content.
- Cord, ribbon and embroidered bands: `paintCraftTrim` and `contourTrimPath`,
  over a path or inside a closed silhouette with a nominal edge gap.
- Six `CraftStitchKind` families share `craftStitchPath`/`paintCraftStitch` and
  puncture geometry: running, backstitch, blanket, chain, cross and basting.
- `CraftPendulum` samples bounded gravity/wind with explicit realistic/cartoon
  response and caller-owned time. It is a rigid suspension model.
- `paintCraftFreehand` renders ordered solid-pen paths/taps under point/stroke
  budgets without treating decorative path length as drawing validity.
- Pencil, chalk and wax extend decorative strokes. `paintWatercolorSpread`
  adds an explicit seeded, organic progress-driven contact front.

## Runnable examples, not new package APIs

The live gallery adds paint spreading, a continuous moving-brush wash and
pink/blue layering studies; needle-free thread passage, missing-stitch completion
and whole-embroidery reveal remain distinct uses. Playback is finite and uses
existing progress/activity/reduced-motion contracts. Brush, loose-thread and
needle props are independently configurable in the corresponding examples.

The experience-frame recipe fits synthetic imported artwork while keeping
heading, form and a measured footer native, including narrow/short screens,
250% text and simulated keyboard insets. Shared crop/hinge factories remain
example-owned. The video integration guide documents consumer adapters without
adding Fluvie/Social Studio dependencies or a job parser to the core package.

## Upgrading from 0.1.0

Update exhaustive `CraftStrokeTool` switches for `pencil`, `chalk` and `wax`.
Choose the appropriate behavior explicitly; do not silently treat these tools as
solid freehand, which still supports the pen contract. The enum extension is why
this is a pre-1.0 minor release rather than a patch.

```yaml
dependencies:
  handcrafted_flutter:
    git:
      url: https://github.com/moisesaguiarjunior/handcrafted_flutter.git
      ref: v0.2.0
```

Run `flutter pub get`, commit the consumer lockfile and run that application's
behavior, accessibility and visual-parity checks in its own PR. This release does
not migrate consumers or approve visual changes on their behalf. Existing tags
and immutable source pins are preserved. `authoredKiteTail` was already removed
in 0.1.0 and is not reintroduced.

## Evidence and limits

The integrated implementation passed strict analysis/formatting, 94 package and
89 example tests, focused Chrome checks, independent exact-SHA reviews and web
release builds. The release candidate repeats the repository checks; its PR,
release tag and CI records identify the final reviewed source. No golden baseline
is regenerated for this release. See [review record](../reviews/local-review-record.md).

Direct dependencies and audited hosted dependency versions are unchanged:
Flutter and clipper2 0.0.3 (BSL-1.0); example fonts retain their OFL notices.
[Dependency inventory](../dependency-license-audit.md).

Actual Android/iPhone performance, physical-device keyboard/screen-reader
validation and consumer adoption remain pending. These are bounded visual
materials and motion recipes, not a fluid, flexible-rope or cloth solver. Further
fabrics, filled embroidery, extraction tooling and recipe-book work remain on the
[tasklist](../tasklist.md).
